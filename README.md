# AntiStress Legal

Legal and support pages for the **AntiStress** iOS app, a collection of calm, touchable worlds.

- **Privacy Policy:** <https://hadicuet.github.io/antistress-legal/>
- **Support:** <https://hadicuet.github.io/antistress-legal/support.html>
- **Terms of Use:** Apple's standard EULA, <https://www.apple.com/legal/internet-services/itunes/dev/stdeula/>
- [`privacy-policy.md`](privacy-policy.md) and [`support.md`](support.md) are the Markdown sources; `index.html` and `support.html` are the hosted pages, built from them with `python3 build.py`.
